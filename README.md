## ⚠️ 重要：报价系数不得外发

文档 01、03 与「完整执行版」含**报价系数（×0.8 – ×1.5）与毛利基准**，属内部定价数据。

对外材料请勿引用这些数字——客户看到「你在汽配只收 0.8 倍」会觉得你在占便宜，看到「珠宝 1.5 倍」会觉得你在宰他。

**对外解释逻辑应改为**：用行业服务投入的差异说明价格差异。例如——
> 珠宝卖的是信任与故事，内容与信任构建成本最高，溢价也最高；
> 汽配是 B2B 逻辑、复购频次高，是长期现金流最稳的一类，因此服务单价相对低。

## 合规红线（已在各文档中固化）

1. **不承诺「包过」** — 高企认定是省级专家评审，2025 年专精特新申报淘汰率已达 83%
2. **不按补贴金额抽成** — 普遍 10–20% 抽成已被多地监管定性违规，机构涉骗补一律移送公安（台州判例：有期徒刑一年缓一年六个月）
3. **不碰材料造假** — 伪造租赁合同骗取补贴构成诈骗罪
4. **第三方费用实报实销** — 检测、审计、官费一律不加价、不赚差价
